# Thư mục ảnh học sinh theo lớp

Mỗi thư mục con = một lớp (cùng tên với `danh-sach/`).

## Cách đặt tên file

Đặt tên ảnh theo **mã học sinh**:

- `HS019.jpg` / `HS019.png` / `HS019.webp`
- hoặc chỉ số: `19.jpg`

App sẽ gắn ảnh lên ô sơ đồ tự động.

## Cách thêm ảnh

1. **Trên web (đã đăng nhập):** mục «Ảnh học sinh trên sơ đồ» → chọn nhiều file → Tải ảnh lên; hoặc chạm ô HS → Thêm ảnh.
2. **Qua GitHub:** copy ảnh vào `anh-lop/<tên lớp>/` rồi commit/push để Render giữ lâu dài (máy Render free mất file khi restart nếu chỉ upload trên web).

## Lưu ý Render Free

Upload trên web lưu tạm trên ổ đĩa ephemeral. Muốn giữ ảnh: commit thư mục `anh-lop/` lên GitHub (hoặc gắn Persistent Disk).
